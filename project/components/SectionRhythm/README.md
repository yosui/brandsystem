# SectionRhythm

ページを縦に読み進めるとき、セクションの地を「明るい → 淡い色付き → 暗い」と切り替えてリズムを作る見本です。

- **明るい（`bg`）:** ヒーロー。中央揃えの巨大な見出しと主ボタン1つ。記号の円を下端からはみ出させる。
- **淡い色付き（`jade-tint`）:** 数字や特徴を3列で並べる。数字は `jade-text`。
- **暗い（`ink`）:** 文字は `on-ink`。中に `surface` の白いカード（`radius-sm`）を入れて、数字を見せる。
- **セクション同士の間:** 64〜80px（`space-16` 以上）。
