# Button

ユーザーに次の行動をうながす、完全な丸（pill）のボタンです。

## 種類
- **主（primary）:** `jade` の塗りに `ink` の文字。画面の中でいちばん大事な行動に1つだけ。
- **副（secondary）:** `fill-subtle` の淡い塗り。主ボタンと並べる2つめの行動。
- **第三（tertiary）:** 塗りなし・下線付き。「詳しく見る」「あとで」など軽い行動。
- **危険（negative）:** `danger` の塗りに白い文字。取り消せない操作の最終確認だけ。

## サイズ
- **大（lg）:** 高さ 56px。画面の最後の行動、ボトムに固定するボタン。
- **中（md）:** 高さ 48px。標準。
- **小（sm）:** 高さ 32px。カードやリストの中。

## 使い方
- **1画面に主ボタンは1つ:** 並べるなら主＋副、または主＋第三。
- **ラベルは動詞から:** 「送金する」「続ける」。「OK」「はい」は使わない。
- **スマートフォンでは画面幅いっぱい（block）:** 縦に積むとき、主ボタンを上に置く。
- **状態:** マウスを乗せると `jade-hover`、押すと `jade-active`。副は `fill-subtle-hover` / `fill-subtle-active`。
- **無効状態はなるべく使わない:** 押せない理由が分からなくなるため、押させてからエラーで理由を伝える。
