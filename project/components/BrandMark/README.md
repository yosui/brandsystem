# BrandMark

`jade` と `violet` の円を重ね、重なった部分を `overlap` で塗ったブランドマークです。

- **比率:** 円の中心どうしの距離は直径の約 0.55 倍。`jade` が左上、`violet` が右下。
- **地:** `bg`、`surface`、`ink` のいずれか。写真やブランド色の面の上には置かない。
- **最小サイズ:** 円の直径 16px。
- **作り方:** SVG で2つの円を描き、`jade` の円をもう一度 `violet` の円でクリップして `overlap` で塗ります。使う側は `tokens.css` の色トークンを読み込んでください。
