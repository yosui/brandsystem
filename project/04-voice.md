# Voice

数字は正確に、ことばは隣の人に話すように。お金のことは正直に言い切り、余計な飾りは付けません。

## トーン

- **言い切る:** 「〜となっております」「〜させていただきます」は使いません。「手数料は ¥480 です。」と事実をそのまま書きます。
- **隠さない:** 手数料、為替レート、着金までの時間は、聞かれる前に先に出します。
- **短く:** 1文に伝えることは1つ。ボタンは動詞1つ（「送金する」「受け取る」）。
- **人懐っこく、なれなれしくない:** 「おはようございます」は言っても、「！」や絵文字は使いません。

## 書き方の例

| 場面 | こう書く | こう書かない |
| --- | --- | --- |
| 手数料 | 手数料は ¥480 です。表示以外の費用はかかりません。 | 業界最安水準の手数料でご利用いただけます！ |
| 完了 | 送金しました。明日までに届きます。 | 送金処理が正常に完了いたしました。 |
| エラー | カード番号が違うようです。もう一度入力してください。 | エラーが発生しました（E-1023）。 |
| ボタン | 送金する | こちらをタップして送金手続きへ進む |
| 空の状態 | 最初の送金をしてみましょう。 | データがありません。 |

## 英語のことば

英字は Darker Grotesque で、あいさつやボタンのような短いフレーズだけに使います（「Good morning」「Send」「Receive」）。説明文は和文で書きます。

## 数字の書き方

- **通貨記号は前:** ¥128,000、$1,240.50。
- **桁区切りはカンマ:** 4桁から付けます。
- **入出金は符号を付ける:** +¥328,000、−¥12,400。マイナスはハイフンではなく「−」（U+2212）を使います。
- **レートは小数2桁:** 1 USD = 151.42 JPY。時刻を `caption` で添えます。
