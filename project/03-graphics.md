# Layout & Shape

形・余白・ふるまいは Wise の構造そのままです。

## 角丸

| トークン | 値 | 使う場所 |
| --- | --- | --- |
| `radius-sm` | 10px | 入力欄、セレクト、インラインのお知らせ、Snackbar |
| `radius-md` | 16px | リスト行、InfoPrompt、タイル、Popover |
| `radius-lg` | 24px | カード、モーダル、ボトムシート、プロモカード |
| `radius-xl` | 32px | 画面幅いっぱいのセクションパネル |
| `radius-pill` | 9999px | ボタン、チップ、タブ、セグメント、スイッチ、アバター |

ボタン・チップ・タブに 0〜4px の角は使いません。

## 輪郭と影

- **カードの縁は `ring` だけ:** 1px、ink の 12% の輪郭です。ぼかした影、グラデーション、ぼかし効果は使いません。
- **フォーカスは `ring-focus`:** ink の 2px の内側の線。光らせません。

## 余白

4px を基準にした段階です。

- **要素同士:** `space-2` 8px〜`space-3` 12px
- **カードの内側:** `space-6` 24px（セクションパネルは `space-10` 40px）
- **入力欄:** 上下 `space-3` 12px、左右 `space-4` 16px
- **入力欄の高さ:** 48px（ボタンの中サイズと同じ）
- **列同士・カード同士:** `space-8` 32px
- **セクション同士:** `space-16` 64px〜80px
- **画面幅:** 最大 1200px で中央寄せ。ヒーローと暗いセクションは画面幅いっぱい。

## ボタンのふるまい

- **主ボタン:** `jade` の塗りに `ink` の文字、`radius-pill`。1画面に1つだけ。
- **副ボタン:** `fill-subtle` の塗りに `ink` の文字。
- **第三のボタン:** 塗りなし、下線付き。主ボタンの隣に置く軽い行動はこれにする。
- **マウスを乗せたとき・押したとき:** 塗りの色だけを一段濃くする（`jade-hover` / `jade-active`、`fill-subtle-hover` / `fill-subtle-active`）。大きさや形は変えない。
- **高さ:** 大 56px、中 48px、小 32px。

## レイアウト

- **ヒーロー:** 中央揃えで、巨大な見出しを1つ。広い余白。図形を画面の下端や角からはみ出させる。
- **補足のセクション:** 文章とビジュアルの2列、または特徴を並べる3列。スマートフォンでは1列。
- **ナビゲーション:** 上部に固定した1本のバー。左に記号、右に丸いボタン。
- **アイコン:** 24px の線のアイコン。国や通貨は円形の旗で示す。

## 図形

- **記号:** `jade` と `violet` の円を重ね、重なりを `overlap` で塗る。中心どうしの距離は直径の約 0.55 倍。`jade` が左上、`violet` が右下。最小は円の直径 16px。
- **画像も円か大きな角丸で切り抜く:** 写真や旗は円形、または `radius-lg` 以上。
- **大きく、少なく:** 1画面に置く円は2〜3個まで。文字の下には敷かない。
