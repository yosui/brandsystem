# Brand System

数字は硬く、言葉は人懐っこく。

配色と書体だけをこのブランドのものに替え、それ以外の形・余白・部品・ふるまい・レイアウトはすべて Wise のデザインシステムの構造に合わせています。迷ったら「Wise ならどうしているか」を基準にしてください。

## Wise から引き継いでいるもの

- **ボタンはすべて完全な丸（pill）:** 主ボタンはブランド色の塗りに濃い文字、副ボタンは淡い塗り。マウスを乗せると少し大きく、押すと少し縮む。色は変えない。
- **影は使わない:** カードの縁は 1px の薄い輪郭（`ring`）だけ。ぼかした影やグラデーションはなし。
- **角丸は大きさで段階を付ける:** 入力欄と標準カードは 10px、小さいカードは 16px、特集カードは 30px、画面幅いっぱいのパネルは 40px。
- **セクションの地を切り替えてリズムを作る:** 白 → 淡い色付き → 暗い、の順に地を変える。
- **大見出しは巨大に、極太で、行間を詰める:** 余白を広く取り、見出しを1つだけ大きく置く。
- **主役のブランド色は1セクションに1か所:** 何か所にも散らさない。

## このブランドのもの

| 要素 | 値 |
| --- | --- |
| 地 | `bg` #F4F7FA、カードは `surface` #FFFFFF |
| 文字 | `ink` #101828、補足は `ink-muted` #4A5468 |
| ブランド色 | `jade` #00A88F（主ボタン）、`violet` #5B4BFF、重なりは `overlap` #1D3B8F |
| 書体 | Big Shoulders Display（数字・大見出し）、Darker Grotesque（ことば・ボタン）、M PLUS 1（和文・本文） |
| 記号 | `jade` と `violet` の円の重なり |

## 章

- **Color:** 色の役割と、組み合わせてよい文字色
- **Typography:** 3書体の役割とスケール
- **Layout & Shape:** 角丸・余白・輪郭・セクションの切り替え・図形
- **Voice:** ことばのトーンと書き方
- **Components:** 部品の一覧と使い分け（Wise の部品ライブラリと同じ構成）
- **Assets:** 旗・アイコン・図形・写真・ロゴの使い方

Components のページに全39部品の見本と使い方、Assets のページに円形の旗とアイコンがあります。
