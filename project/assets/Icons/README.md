# Icons

24px の線のアイコンです（Lucide、ISC ライセンス）。線の太さ 2px、線の端は丸。インクは `ink` #101828 で書き出してあります。

- **サイズ:** 24px が標準。InlinePrompt や入力欄の中だけ 16px。
- **色:** `ink` のまま使う。暗い地の上で使うときは、`on-ink`（白）で書き出し直す。
- **意味が一つに決まるものだけ:** 送金（send）、受け取る（arrow-down-left）、両替（arrow-left-right）、入金（plus）、銀行（landmark）。
- **アイコンだけのボタンには読み上げ名を付ける。**
- **塗りのアイコン・多色のアイコンは使わない:** 色が付くのは旗だけ。
