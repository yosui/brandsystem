# Assets

アセットの種類と使い方は Wise の構成に合わせています。Wise 自身の旗・アイコン・イラストはライセンス上使えないため、同じ使い方ができるオープンな素材に置き換えています。

## 旗（Flags）

- **円形の旗で国と通貨を表す:** Wise と同じく、旗が唯一の「色の付いたアイコン」です。
- **素材:** circle-flags（MIT）。Assets の Flags に主要14か国・地域があります。
- **サイズ:** 24px（チップ・入力欄・リスト）、48px（カード）、20px（アバターのバッジ）。

## アイコン（Icons）

- **24px の線のアイコン:** 線の太さ 2px、端は丸。色は `ink`。
- **素材:** Lucide（ISC）。Assets の Icons に送金アプリでよく使う29個があります。
- **塗りや多色のアイコンは使わない。**

## イラストと図形

- **イラストの代わりに記号の円を使う:** `jade` と `violet` の円とその重なり。ヒーロー、プロモカード、空の状態の画面に大きく置き、角や端からはみ出させる。
- **立体的なイラスト（Wise の地球やコインのような）が必要になったら:** 円の重なりをモチーフに、`jade`・`violet`・`overlap` の3色だけで新しく描き起こす。

## 写真

- **明るく、白っぽい、人物が自然に写っているもの。**
- **切り抜きは円か `radius-lg` 以上の角丸。**
- **写真の上に文字を重ねない:** 文字は白い面の上に置く。

## ロゴ

- **記号（2つの円の重なり）＋ブランド名:** ブランド名が決まったら、Big Shoulders Display で組んだロゴタイプを追加します。
