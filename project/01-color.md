# Color

色の使い方の構造は Wise と同じです。明るい地に濃いインクの文字。ブランド色は主ボタンと記号だけに使い、1セクションに1か所までにします。

## 色の役割

| トークン | 値 | 役割（Wise での対応） |
| --- | --- | --- |
| `bg` | #F4F7FA | 画面の地 |
| `surface` | #FFFFFF | カード |
| `ink` | #101828 | 文字、暗いセクションの地（Wise の濃い文字色） |
| `ink-muted` | #4A5468 | 補足文・ラベル |
| `hairline` | #E2E7EE | 区切り線 |
| `fill-subtle` | ink の 8% | 副ボタン・チップの淡い塗り |
| `jade` | #00A88F | 主ボタンの塗り（Wise のライムの位置） |
| `violet` | #5B4BFF | 記号の円、イラストの面 |
| `overlap` | #1D3B8F | 記号の重なり、強調する数字 |
| `on-ink` | #FFFFFF | 暗いセクションの文字 |

## 意味を伝える色

| トークン | 値 | 使う場面 |
| --- | --- | --- |
| `jade-text` / `jade-tint` | #00705E / #E6F6F3 | 入金・成功。`jade-tint` は明るい色付きセクションの地にも使う |
| `violet-text` / `violet-tint` | #4A3BE0 / #EEECFF | テキストリンク / 選択中・お知らせ |
| `danger` / `danger-tint` | #B4233C / #FDECEE | エラーと取り消せない操作だけ |

- **入金と出金は記号で区別:** 入金は `jade-text` に「+」、出金は `ink` に「−」。
- **赤はエラー専用:** 装飾には使いません。

## セクションの地

Wise と同じく、セクションごとに地を切り替えてリズムを作ります。

1. **明るい:** `bg`。いちばん多い。
2. **淡い色付き:** `jade-tint`。特徴の説明や比較など、少し目立たせたい内容。
3. **暗い:** `ink`。文字は `on-ink`。中に `surface` の白いカード（角丸 10px）を入れる。

## 組み合わせてよい文字色

| 地 | 文字 | コントラスト |
| --- | --- | --- |
| `bg` | `ink` / `ink-muted` / `overlap` | 16.5:1 / 7.1:1 / 9.4:1 |
| `surface` | `ink` / `ink-muted` / `violet-text` | 17.8:1 / 7.6:1 / 7.0:1 |
| `jade` | `ink`（主ボタン） | 5.9:1 |
| `ink` | `on-ink` | 17.8:1 |
| `violet` | `on-ink` | 5.4:1 |
| `jade-tint` | `ink` / `jade-text` | 15.9:1 / 5.4:1 |
| `danger-tint` | `danger` | 5.7:1 |

使わない組み合わせ：`jade` や `violet` を文字色にすること、`jade` の上の白い文字（3.0:1）、`violet` の上の `ink` の文字（3.3:1）。
